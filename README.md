# 不定詞・動名詞 Quest

PDF「不定詞・動名詞セット集」をもとにした、英語→日本語／日本語→英語の4択クイズです。

## GitHub Pagesで公開する方法
1. GitHubで新しいPublicリポジトリを作成（例：`infinitive-gerund-quest`）。
2. このフォルダ内の `index.html` をリポジトリ直下にアップロード。
3. リポジトリの **Settings → Pages** を開く。
4. **Deploy from a branch** を選択し、Branchを `main`、Folderを `/ (root)` にして Save。
5. 数分後に表示されるURLをChromebookやGoogle Classroomで共有。

## ゲームモード
- タイムアタック：60秒間の正解数を記録
- ハート3つ：3回間違えると終了
- 間違い克服：一通り解いたあと、間違えた問題だけを復習

データはブラウザ内で動作し、ログインやサーバーは不要です。
